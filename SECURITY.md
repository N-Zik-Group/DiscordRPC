# 🔒 Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in DiscordRPC, **please report it immediately** using one of the following channels:

- 💬 **Discord:** contact the developers directly on the [N-Zik Discord](https://discord.gg/bneHC7QRje)
- 🐛 **GitHub:** open an issue using the [🔒 Security Vulnerability template](https://github.com/N-Zik-Group/DiscordRPC/issues/new?template=security_report.yaml)

Please include as much detail as possible (affected version or commit, steps to reproduce, potential impact) so we can fix it quickly.

Thank you for helping keep DiscordRPC and its users safe!
